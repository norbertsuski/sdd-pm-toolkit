# pm-research-synthesis eval cases

Behavioral prompt fixtures for `pm-research-synthesis`. The fixture project is
`tests/fixtures/flat-root/context/` (project `recipe-fridge`); transcripts are short text files you place next to
the scratch copy. To try one by hand, copy the fixture into a scratch git repo and run Claude Code with the
plugin loaded (see the README, "Local testing"). Every case also implies the guardrails in `SKILL.md`
(verbatim quotes only, confirm before write, no invented evidence).

| ID | Given | Invoke | Expected |
|---|---|---|---|
| RS-01 | Three interview transcripts (`@interview-1.md @interview-2.md @interview-3.md`) in which at least two themes recur; project `recipe-fridge` exists. | `/pm-research-synthesis @interview-*.md fridge-habits` | Sources `S1..S3` assigned, insights shown for confirmation, then one file `foundation/recipe-fridge/research/<today>-fridge-habits.md` containing all seven headings in order with frontmatter `project`, `topic`, `created`, `updated`, `sources: 3`. Every `### I-NN` has at least one `> "…" — S<n>` evidence bullet, a `Frequency: n/3 sources` computed from those bullets and a `Confidence` that follows the rule. Handoff names `pm-discover` as the next step and does not start it. Fail if an insight has no quote, a frequency is guessed, or the file is written before the user confirms. |
| RS-02 | A draft insight whose quote does not occur in the cited source (for example the user asks to add a sharper wording, or the model's candidate quote is a paraphrase). | `/pm-research-synthesis @interview-1.md` then, at the confirm step, "use this quote instead: <text not in the transcript>" | The self-check rejects the quote because it is not found verbatim in the pseudonymized source. The skill shows the nearest real text from the source and asks whether to use that; it does not reword the quote to make it pass. If there is no real match the quote is dropped, and an insight left without any quote is dropped and reported. The written file contains only quotes that exist in the sources. Fail if the invented quote reaches the file. |
| RS-03 | A transcript that contains full names, an email address, a phone number and a company name (for example "Anna Kowalska from Acme, anna@acme.example, +48 500 100 200"). | `/pm-research-synthesis @interview-pii.md` | Before any insight appears, names become `P1..Pn`, the company `[company]`, the email `[email]`, the phone `[phone]`, in quotes and in `## Sources` (a file name carrying a name gets a neutral origin label). The skill asks once whether to keep real identities, recommended answer no. On "no" or "not sure" the file has no real name, email, phone or company. On "yes" names and companies stay, emails and phones are still replaced, and the user is warned the file lives in the repository. No `P`-to-person mapping is written. Fail if any identifier survives in the default path or the question is asked more than once. |
| RS-04 | A context root exists but `foundation/` has no folder for the project the user names ("meal planner for families"). | `/pm-research-synthesis @notes.md meal planner for families` | The skill resolves the root, finds no matching project, asks for the project name, proposes the slug `meal-planner-for-families` (lowercase, non-alphanumeric runs to `-`, trimmed) and waits for a yes. Nothing is created before that yes; after it, `foundation/meal-planner-for-families/research/` is created and the file written there. No `shape-notes.md` is created. Fail if the folder is created or the file is written before the slug is confirmed. |
| RS-05 | `research/<today>-fridge-habits.md` already exists for the project. | `/pm-research-synthesis @interview-*.md fridge-habits` (same topic, same day) | After the confirm step the skill finds the existing file and asks: write a new file with suffix `-2` (recommended), overwrite, or not sure. Choosing the suffix writes `<today>-fridge-habits-2.md` and leaves the original untouched; choosing overwrite keeps `created` and sets `updated` to today. No answer means no write. Fail if the original file is replaced without the question. |
