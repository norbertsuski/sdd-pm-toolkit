# pm-forecast eval cases

Behavioral prompt fixtures for `pm-forecast`. The fixture project is `tests/fixtures/flat-root/context/` (project `recipe-fridge`; four archived
changes, `auth-scaffold` 2026-09-29, `fridge-inventory` 2026-10-01, `recipe-match` 2026-10-08, `save-favorites` 2026-10-14; remaining items
`shopping-list` (proposed), `meal-plan` (ready), `share-recipe` (blocked); PRD `timeline_budget: { hard_deadline: 2026-12-15 }`). Today in these
cases is 2026-10-20, so the weekly throughput is `[2, 1, 1]` and the script prints p50/p85/p95 = 2/3/3 weeks (2026-11-03, 2026-11-10, 2026-11-10).
The shared fixture is **not changed**: where a case needs a different state the Given describes the variant to apply to a scratch copy. The
script behaviour is covered by `tests/test_forecast.py`; these cases cover what the skill says and writes. Every case also implies the guardrails
in `SKILL.md` (never edits the roadmap, never presents a single date, caveats always written, no invented history).
