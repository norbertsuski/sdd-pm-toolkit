# pm-prioritize eval cases

Behavioral prompt fixtures for `pm-prioritize`. The fixture project is `tests/fixtures/flat-root/context/` (project `recipe-fridge`: `roadmap.md`
with F-01 and S-01..S-06; F-01, S-01, S-02 and S-03 are `done`; S-04 `proposed` with Prerequisites `S-02, ingredient unit convention agreed`; S-05
`ready` with `changes/meal-plan/` at `status: implementing` and Prerequisite `S-03`; S-06 `blocked` (Unknown `Block: yes`) with Prerequisite `S-04`;
greenfield `prd.md` with FR-001..FR-005). The shared fixture is **not changed** for these cases: where a case needs a different state, the Given
describes the variant to apply to a scratch copy. To try one by hand, copy the fixture into a scratch git repo and run Claude Code with both plugins
loaded (see the README, "Local testing"). Every case also implies the guardrails in `SKILL.md` (never edits the roadmap, never invents an input,
computes with `python3 -c`, done items excluded, no silent overwrite).

Scores in the cases are what the commands in `SKILL.md` print for the inputs given (reach counted as "households per month").
